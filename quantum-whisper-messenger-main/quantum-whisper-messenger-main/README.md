# Quantum Whisper Messenger

A Post-Quantum Cryptography Based Messaging Framework for Web and Mobile                                              Cryptography, Secure Communication  • Designed and implemented a post-quantum secure messaging framework using CRYSTALS-Kyber (key exchange) and CRYSTALS-Dilithium (digital signatures) to protect against quantum attacks. • Delivered end-to-end encrypted, quantum-resistant communication with low latency and forward secrecy for web and mobile platforms. • Tools: Post-Quantum Cryptography (PQC), Lattice-Based Cryptography, CRYSTALS-Kyber, CRYSTALS-Dilithium, React.js, Node.js. Also published the research outcomes in IEEE, demonstrating practical implementation of advanced cryptography.
